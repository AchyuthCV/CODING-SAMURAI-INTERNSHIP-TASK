# 🎯 Project 4: Number Guessing Game with GUI

A simple **Python GUI-based Number Guessing Game** built using **Tkinter**.  
The program randomly generates a number, and the user tries to guess it with the help of hints.

---

## 📌 Project Description

This project demonstrates the use of:
- Python programming
- GUI development using Tkinter
- Random number generation
- Event-driven programming

The application provides feedback such as **Too High**, **Too Low**, or **Correct**, and displays the number of attempts taken by the user.

---

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter (GUI library)**
- **Random module**

---

## ⚙️ How the Game Works

1. The program generates a random number between **1 and 100**
2. The user enters a number in the input box
3. On clicking **Check Guess**:
   - If the guess is too low → displays *Too Low*
   - If the guess is too high → displays *Too High*
   - If correct → displays success message with number of attempts
4. The game ends when the correct number is guessed
