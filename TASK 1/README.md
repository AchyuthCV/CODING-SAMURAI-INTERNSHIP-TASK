# 🌦️ Task 1 – Weather App (Python)

## 📌 Description
A Python-based weather application that fetches real-time weather data using the OpenWeather API.

## 🚀 Features
- Takes city name as user input
- Fetches live weather data using API
- Displays temperature, humidity, and weather condition
- Handles API errors gracefully

## 🛠 Tech Stack
